# TaskFlow

TaskFlow is a personal productivity and task management web application.

## Features

- User registration and login
- Personalized user greeting
- Create, edit and delete tasks
- Mark tasks as completed
- Productivity percentage tracking
- Task filtering
- Search functionality
- Dark mode support
- Local data storage

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage API

## Purpose

TaskFlow helps users organise their daily activities, monitor progress and improve productivity.
